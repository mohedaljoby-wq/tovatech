# NovaTech

A complete front-end-only academic project using HTML5, CSS3, JavaScript and the requested CDN libraries.

## Run
1. Extract `NovaTech.zip`.
2. Open `index.html` in a browser.
3. Internet access is recommended because Bootstrap, jQuery, Font Awesome, Toastify, Swiper, Google Fonts, and Picsum images are loaded from CDNs.
4. On `services.html`, the details modal first attempts Ajax against `data/services.json`. If the browser blocks local `file://` Ajax, the built-in JavaScript fallback displays the same content.

## Libraries
- Bootstrap 5.3.2
- jQuery 3.7.1
- Font Awesome 6.5.1
- Toastify.js
- Swiper.js 11
- Google Fonts / Poppins

## Notes
- No backend or server-side code is included.
- `videos/` is intentionally empty/reserved.
- Images use Picsum placeholders.
- Forms demonstrate client-side validation only; no information is sent to a server.
